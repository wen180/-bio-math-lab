# 📚 参考资料与书单（references/）

按阶段组织的教材、论文与公开课。

**阅读方式三档：**

- **精读**：逐节读 + 做课后题（核心数学与经典论文必须精读）；
- **查阅**：用到时查相关章节，不通读；
- **泛读**：读主线、跳过证明细节，建立全景地图。

进入某阶段前，先看该阶段的**精读**项；查阅型教材放在手边备查。

## 获取方式提示

- **公开课**：3Blue1Brown（YouTube / B 站官方频道）、Khan Academy（官网）——免费直接访问。
- **论文**：通过 Google Scholar、出版商页面或大学图书馆数据库获取正式版本；Raissi 2019 与 Karniadakis 2021 等有 arXiv / 作者预印本版本；van de Schoot 2021 为开放获取。
- **教材**：Strogatz、Alon、Murray、Wilkinson、McElreath 等优先走大学图书馆与馆际互借；需要自购电子书时走出版社官方渠道。
