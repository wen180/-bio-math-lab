# 🗒️ 概念笔记（notes/）

这里存放**费曼式笔记**：一个概念一篇，用自己的话重述，而不是抄书。

## 一篇合格的笔记必须包含

1. **用自己的话重述概念** —— 写不出来，说明还没懂，回去重学；
2. **一个具体的生物学例子** —— 最好与细胞生物学背景相关；
3. **一个疑问** —— 留给下一次学习或 AI 评审解决。

## 命名规范

- 一个概念一个文件，kebab-case 命名：`linear-stability.md`、`nullcline.md`、`propensity-function.md`；
- 笔记模板见 [template.md](./template.md)，新建笔记先复制模板再填；
- 修正认知后**不删除旧内容**，在"容易混淆的点"或"疑问"处补记——错误是学习轨迹的一部分。

## 与 progress.md 的分工

| 文件 | 记录什么 | 组织方式 |
|---|---|---|
| [progress.md](../progress.md) | 学到了什么程度、卡在哪里 | 按时间（日志） |
| notes/ | 真正弄懂了什么 | 按概念（知识沉淀） |

复习时优先翻 notes/：三分钟讲不清一个概念，就回到讲义重学。
