# 🔁 Stage 01 · 动力学系统与基因调控

> **周期**：6–8 周 ｜ **前置**：Stage 00（微分方程、线性代数稳定性、`solve_ivp`）
> **一句话**：细胞用基因调控回路做"决策"——本阶段学习回路的语言：**反馈、双稳态、振荡**，以及分析它们的完整数学工具箱。

---

## 🎯 学习目标

1. 从生化反应机理（质量作用定律）出发，把基因调控系统翻译成 ODE 模型——而不是直接抄别人的方程；
2. 掌握酶动力学（Michaelis–Menten）与基因调控函数（Hill 函数）的推导、适用条件与滥用警示；
3. 熟练执行**线性稳定性分析**三步法（找平衡点 → 求雅可比 → 判特征值），并能在相平面上用零斜线（nullcline）画出系统的全局行为；
4. 理解**分岔（bifurcation）**：参数微小变化如何引起系统质变（单稳态 ↔ 双稳态 ↔ 振荡）；
5. 能读懂并批判性评估合成生物学两篇奠基论文（toggle switch、repressilator）的模型部分。

## 🧠 核心概念清单

### 建模方法论
- 状态变量的选择（mRNA / 蛋白 / 复合物：什么必须显式建模，什么可以约化）
- **质量作用定律（law of mass action）**：速率 ∝ 反应物浓度乘积；从反应式直接写方程
- 反应速率常数 $k$ 的方向：结合 vs 解离

### 酶与调控函数
- **Michaelis–Menten 动力学**：$v = V_{\max}\frac{[S]}{K_M + [S]}$；准稳态假设（QSSA）的来龙去脉
- **Hill 函数**：激活 $f(x) = \frac{x^n}{K^n + x^n}$ 与抑制 $f(x) = \frac{K^n}{K^n + x^n}$；Hill 系数 $n$ 的合作性含义（$n=1$ 无合作、$n>1$ 协同结合 → 开关性增强）
- 逻辑近似（Boolean-like）与饱和

### 回路行为
- **反馈回路**：正反馈 vs 负反馈；网络模体（network motif，Alon）
- **双稳态（bistability）**：两个稳定平衡点共存 + 一个鞍点分水岭；滞后（hysteresis）
- **振荡（oscillation）**：Goodwin 振荡器、repressilator；振荡的三要素（负反馈 + 延迟 + 足够非线性）
- 自调控加速响应 / 减噪（Alon 第 3 章）

### 分析工具
- 平衡点、**雅可比矩阵与线性稳定性**（Stage 00 讲义 02 §6 的规模化应用）
- **相平面（phase plane）**：零斜线作图、轨迹方向场、鞍点分水岭（stable manifold）
- **分岔**：saddle-node（双稳态的诞生与湮灭）、Hopf（振荡的诞生）；分岔图（把稳定 / 不稳定分支画在参数—状态平面上）
- 多尺度与无量纲化（减少参数、暴露关键组合）

| 场景 | 数学看点 |

| 自负调控基因（负自抑制） | 响应加速、噪声抑制（连接 Stage 02） |
| 细胞周期 / 钙振荡 | 分子机器的节律：极限环的现实范本 |

## 🏁 里程碑项目：`stage01-dynamics` —— repressilator 振荡条件的数值证明

**一句话**：实现 repressilator 的完整数值模拟，找出"振荡存在"的参数窗口，并用线性稳定性分析解释振荡为什么出现、何时消失。

### 项目流程

1. **建模**：写出 6 变量 ODE（3 个 mRNA $m_i$ + 3 个抑制蛋白 $p_i$）：
   $$\frac{dm_i}{dt} = -\gamma_m m_i + \alpha\,\frac{K^n}{K^n + p_{i-1}^{\,n}}, \qquad \frac{dp_i}{dt} = -\gamma_p p_i + \beta m_i \quad (i = 1,2,3 \bmod 3)$$
2. **基准模拟**：用 Elowitz & Leibler 的代表性参数数值求解，画 $p_i(t)$ 三条振荡曲线与相空间中的环；
3. **参数扫描**：系统改变 Hill 系数 $n$（协同性）、翻译强度 $\beta$、降解率比 $\gamma_p/\gamma_m$，记录"振荡 / 不振荡"，绘制参数平面上的**振荡区域图**；
4. **理论解释**：在对称平衡点处解析计算雅可比的特征值，找到 Hopf 边界（特征值实部过零的参数条件），与第 3 步的数值边界叠图对照；
5. **破坏实验**：把任一抑制换成激活（双负变双正），或把环从 3 改成 2 / 4 个基因，观察振荡如何消失——用特征值结构解释奇偶性差异。

### 通过标准

- [ ] 振荡周期与振幅随参数的变化趋势能被 Hopf 分析定性预测
- [ ] 数值振荡区域边界与线性稳定性边界一致（相对偏差 < 15%）
- [ ] 一份 notebook：模型推导（含无量纲化）+ 模拟 + 扫描 + 稳定性分析 + 一页讨论
- [ ] 能口头回答："为什么天然振荡器几乎都需要延迟或高非线性？"
