# 📐 Stage 00 · 数学基础：从生物学直觉到数学语言

> **阶段定位**：整个 bio-math-lab 学习路径的起点，预计 **4–6 周**。
> 面向已具备细胞生物学 / 分子生物学背景、但数学工具停留在大学基础课水平的学习者。
> 目标是把后续建模所需的四大支柱补齐：**微积分（动力学的语言）、线性代数（多变量系统的语言）、概率统计（随机性的语言）、Python 科学栈（把数学变成可运行代码）**。
>
> 本阶段的每一条数学都从同一个问题出发：*这个记号在我的细胞里对应什么？* 我们不追求定理的严格证明，而追求——**看到细胞能想到方程，看到方程能想象细胞**。

## 🎯 学习目标

完成本阶段后，你应当能够：

1. **微积分**：把"细胞数量随时间变化"翻译成微分方程 $\frac{dN}{dt} = f(N)$，理解导数即变化率；手推指数增长与 logistic 模型的解析解；用欧拉法（Euler method）给出数值解，并解释步长对精度的影响。
2. **线性代数**：把"多种分子浓度同时变化"写成 $\frac{d\mathbf{x}}{dt} = A\mathbf{x}$；理解特征值 / 特征向量（eigenvalue / eigenvector）决定系统在每个方向上的增长或衰减速率；用矩阵指数 $e^{At}$ 写出线性系统的演化，并用雅可比矩阵（Jacobian）判断平衡点的稳定性。
3. **概率统计**：为"细胞内离散而随机的分子"选择合适的分布（二项 / 泊松 / 指数 / 正态）；手推泊松分布的极大似然估计（MLE）；说出贝叶斯公式中每一项的概率含义——这是 Stage 04 贝叶斯推断的地基。
4. **Python 科学栈**：独立完成 **数值求解 ODE → 可视化 → 拟合参数** 的完整代码闭环；本仓库此后所有阶段的代码都默认你已掌握这一套工具。

## 🧠 核心概念清单

以下是本阶段结束后，你应当**不查资料就能向同学解释**的概念清单（讲义编号对应 `lectures/` 中的文件）。

### 微积分（讲义 01）
- 导数 = 瞬时变化率；$\frac{dN}{dt}$ 读作"此刻细胞数量的净增速"（分裂 − 死亡）
- 微分方程 = 把"当前状态决定变化速度"写成数学规则；$f(N)$ 不含 $t$ 的自治（autonomous）方程
- 指数增长：$\frac{dN}{dt} = rN \Rightarrow N(t) = N_0 e^{rt}$；倍增时间 $t_2 = \frac{\ln 2}{r}$
- logistic 方程：$\frac{dN}{dt} = rN\left(1 - \frac{N}{K}\right)$；环境容纳量 $K$；拐点 $K/2$；最大增速 $rK/4$
- 欧拉法：$N(t + \Delta t) \approx N(t) + f(N(t)) \, \Delta t$；全局误差 $O(\Delta t)$；步长 − 稳定性权衡

### 线性代数（讲义 02）
- 向量 = 一组浓度（状态）；矩阵 = 一次线性变换（交互规则）
- 特征值 / 特征向量：$A\mathbf{v} = \lambda \mathbf{v}$，变换的不变方向，$\lambda$ 是该方向的伸缩率
- 线性 ODE 系统的解：$\mathbf{x}(t) = e^{At}\,\mathbf{x}(0)$；对角化 $A = PDP^{-1}$ 的意义
- 雅可比矩阵 = 非线性系统在平衡点附近的局部线性近似
- 二维稳定性快速判据：$\operatorname{tr}(A) < 0$ 且 $\det(A) > 0$ ⟹ 稳定

### 概率统计（讲义 03）
- 随机变量、PMF / PDF、期望、方差；噪声强度度量 $\mathrm{CV} = \sigma / \mu$
- 分布谱系：二项 → 泊松（大量稀有事件）；指数（等待时间）；正态（CLT）
- 泊松过程（Poisson process）：分子碰撞到达的数学模型
- 条件概率、全概率公式、贝叶斯公式 $P(\theta \mid D) \propto P(D \mid \theta) P(\theta)$
- 极大似然估计（MLE）：选让"观测到的数据"出现概率最大的参数
- 中心极限定理（CLT）：为什么多细胞平均荧光近似正态

### Python 科学栈（讲义 04）
- NumPy 向量化思维（用数组运算替代 for 循环）
- Matplotlib 基本绘图流程
- `scipy.integrate.solve_ivp`（解 ODE）与 `scipy.optimize.curve_fit`（拟合参数）
- Jupyter Notebook 工作流：讲义推导、代码、图像放在一起

## 🏁 里程碑项目：`stage00-logistic` —— 细胞生长模型完整闭环

**一句话**：把讲义 01 的数学、讲义 04 的工具、练习 1 与练习 4 的代码，组装成"**推导 → 求解 → 拟合**"的完整闭环。这个工作流模板将在后续所有阶段反复出现——第一次在 logistic 上跑通，后面换汤不换药。

### 项目流程

1. **推导（纸笔）**：从两条生物学假设出发——(i) 每个细胞以净速率 $r$ 分裂增殖；(ii) 培养环境的容纳量为 $K$——写出 logistic 方程，并手推解析解
   $$N(t) = \frac{K}{1 + \frac{K - N_0}{N_0} e^{-rt}}.$$
2. **求解（代码）**：同时实现解析解、欧拉法数值解、`solve_ivp` 数值解，**三者画在同一张图上**；再画一张"欧拉法最大误差 vs $\Delta t$"图（对数坐标），观察斜率是否接近 1（一阶方法）。
3. **生成伪实验数据（代码）**：取解析解在若干时间点的值并叠加高斯噪声（模拟血球计数板 / OD600 测量误差）。
4. **参数拟合（代码）**：用 `curve_fit` 从噪声数据恢复 $(r, K, N_0)$，报告估计值与真值的相对误差，画出"数据点 + 拟合曲线 + 真值曲线"。
5. **反思（文字，≤ 300 字）**：若测量噪声增大 10 倍，$r$ 与 $K$ 哪个更难估准？为什么？
   *提示：$K$ 由曲线右端的平台决定，$r$ 由早期斜率决定——你的采样时间范围跨越拐点 $K/2$ 了吗？*

### 通过标准

- [ ] 解析解与 `solve_ivp` 数值解在同一张图上肉眼不可区分
- [ ] 欧拉法在 $\Delta t = 0.1$ 时与解析解的最大相对误差 < 2%（用代码计算，不靠眼睛）
- [ ] `curve_fit` 恢复的 $r, K$ 与真值相对误差 < 10%
- [ ] 一份 Jupyter Notebook，按上面五步组织，末尾附你的反思
