# 🎲 Stage 02 · 随机过程与噪声：细胞是小的，分子是少的

> **周期**：4–6 周 ｜ **前置**：Stage 01（ODE 建模与稳定性）；Stage 00 讲义 03（泊松过程、指数等待）
> **一句话**：一个大肠杆菌里，多数基因的 mRNA 拷贝数 < 10——**当分子按个位数计数时，"平均"会失效，涨落本身成为生物学**。

---

## 🎯 出发点：为什么确定性方程在这里破产

Stage 01 的世界是连续而确定的：浓度沿相平面轨迹平滑演化。但分子是**离散**的、反应是**随机跳跃**的：

- 转录启动依赖少数几个分子的碰撞（泊松过程，Stage 00 讲义 03 §4）；
- 当某 mRNA 平均只有 2 条/细胞时，涨落（$\sqrt{N} \sim 1.4$）与均值同量级——相对噪声 $\mathrm{CV} \sim 1/\sqrt{N}$ 高达 ~70%；
- 确定性 ODE 只追踪均值，**且当系统非线性时甚至均值都不对**（Jensen 不等式）。

于是核心问题变成：**什么时候 ODE 够用？什么时候必须上随机模型？答案不是直觉，是定理与数值实验。**

## 🎯 学习目标

1. 读懂并写出**化学主方程（CME）**——离散状态、连续时间马尔可夫链的演化方程；
2. 从零实现 **Gillespie 直接算法（SSA）**，并理解它为什么是 CME 的**精确**采样（不是近似）；
3. 区分**内禀噪声（intrinsic）**与**外禀噪声（extrinsic）**——Elowitz 双荧光实验的数学结构；
4. 掌握基因表达噪声的定量语言：$\mathrm{CV}^2$、Fano factor、噪声传播；
5. 理解**突发转录（transcriptional bursting）**与两态启动子模型（telegraph model）；
6. 判断"何时随机性不可忽略"的实用准则（分子数阈值、非线性放大、分水岭穿越）。

## 🧠 核心概念清单

- **随机化学动力学**：propensity 函数 $a_j(\mathbf{x})$（通道 $j$ 单位时间反应概率）与化学随机方程
- **化学主方程（CME）**：
  $$\frac{\partial P(\mathbf{x}, t)}{\partial t} = \sum_j \left[ a_j(\mathbf{x} - \boldsymbol{\nu}_j) P(\mathbf{x} - \boldsymbol{\nu}_j, t) - a_j(\mathbf{x}) P(\mathbf{x}, t) \right]$$
  ——状态概率的"流入 − 流出"收支方程（与讲义 01 的方向场同一哲学：状态决定速率，只是对象从浓度变成了概率）
- **Gillespie 直接算法（SSA, 1977）**：两步采样——指数等待时间 + 按 propensity 加权选通道；每一步都是精确的
- **确定性极限**：大体积极限下 CME → 反应速率方程（ODE）；均值方程与线性噪声近似（LNA）作为中间地带
- **基因表达噪声**：内禀 vs 外禀；双报告基因实验（Elowitz et al. 2002）；噪声在级联中的传播与衰减
- **突发转录（transcriptional bursting）**：两态启动子（telegraph model）；稳态 mRNA 分布从泊松（Fano=1）到负二项（Fano>1）
- **扩散与随机游走**：$\langle x^2(t)\rangle = 2Dt$（一维）；Fick 定律的随机解释；蛋白 vs 小分子的 $D$ 差异（~1–10 μm²/s vs ~1000 μm²/s）与"well-mixed（均匀混合）"假设的有效半径
- τ-leaping 与其他加速方法（概念层面即可）

## 🧫 生物学场景

| 场景 | 数学看点 |
|---|---|

| **分子搜索启动子**（lac 阻遏蛋白） | 三维扩散 + 一维滑移的组合搜索策略 |

## 🏁 里程碑项目：`stage02-noise` —— SSA 模拟低拷贝基因表达

**一句话**：用 SSA 模拟最简基因表达回路（转录 + 翻译 + 降解），扫描平均拷贝数与突发大小，定量回答"**噪声强度如何随拷贝数标度**"。

### 项目流程

1. **实现 SSA**：两反应通道系统（出生–死亡）起步：
   DNA $\xrightarrow{k_\mathrm{ts}}$ mRNA $\xrightarrow{\gamma_m}$ ∅，逐通道验证与解析稳态泊松分布一致；
2. **扩展到蛋白**：加翻译通道（mRNA → 蛋白，速率 $k_{tl}$；蛋白降解 $\gamma_p$），实现完整两层级联的 SSA；
3. **对照确定性极限**：同一参数下并排运行 ODE（Stage 01 工具）与 SSA，画出"单条随机轨迹 vs 均值轨迹 vs 多轨迹平均"——多轨迹平均应收敛到 ODE（何时偏离？非线性时）；
4. **标度律实验**：扫描翻译速率（等价于突发大小 $b = k_{tl}/\gamma_m$）与平均 mRNA 数，绘制
   - 蛋白 Fano factor vs 平均蛋白水平；
   - $\mathrm{CV}^2$ vs 平均拷贝数（对数–对数），验证 $\mathrm{CV}^2 \propto 1/\langle p\rangle$（泊松极限）与突发修正 $b$ 的进入方式；
5. **结论**：给出"你的系统需要随机模型吗"的一页判据（分子数、burst size、非线性增益、噪声敏感的下游决策）。
