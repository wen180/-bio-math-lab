# 🌡️ Stage 03 · 空间与多尺度建模

> **周期**：4–6 周 ｜ **前置**：Stage 01（ODE 与稳定性分析）；Stage 02（随机游走与扩散系数的微观来历）
> **一句话**：细胞不是充分搅拌的试管——**空间不均匀性不是噪声，而是信息**：胚胎的头尾、菌落的环纹、皮肤的花纹，都来自"反应 + 扩散"的自我组织。

---

## 🎯 学习目标

1. 从随机游走出发推导**扩散方程**，让 $\partial u/\partial t = D\nabla^2 u$ 的每一项都有微观来历；
2. 给**扩散系数 $D$** 装上物理与生物学直觉（量级、测量方法、对分子大小的依赖）；
3. 掌握反应扩散 PDE 的**有限差分数值解法**（显式格式、稳定性条件、边界条件选择）；
4. 理解**图灵不稳定性**的完整逻辑链：均匀定态为何在**加入扩散后**反而失稳、为何失稳挑出特定波长（斑图的尺度选择）；
5. 了解**多尺度建模范式**：compartment（分区）模型与 agent-based（个体）模型的定位与代价。

---

## 🧠 核心概念清单

- **反应扩散方程（reaction–diffusion equation）**：
  $$\frac{\partial u}{\partial t} = D\nabla^2 u + f(u) \qquad \text{（扩散项：抹平；反应项：制造）}$$
  —— $f(u)$ 是 Stage 01 的全部动力学内容，$\nabla^2$ 是新增的空间算符
- **扩散系数的物理意义**：$\langle x^2 \rangle = 2nDt$（$n$ 维）；$D$ 的量纲 μm²/s；蛋白 ~1–10、小分子代谢物 ~1000、细胞在组织中原位可以慢到 ~0（被基质锚定）；
- **图灵不稳定性（Turing instability）**：两组分系统（激活子 + 抑制剂，$D_v \gg D_u$ 的"短程激活、长程抑制"）中，**扩散使稳定均匀态失稳**——线性稳定性分析在空间傅里叶模 $e^{iqx}$ 上逐波长进行；
- **斑图形成（pattern formation）**：斑点 / 条纹 / 迷宫；特征波长 $q_c$ 的线性预测 vs 模拟实测（波长选择）；非线性饱和决定最终振幅；
- **PDE 有限差分法**：空间网格与显式时间步进；**稳定性条件** $\Delta t \le \frac{\Delta x^2}{2D}$（一维单组分；多维多组分按 $2nD$ 收紧）；边界条件（周期 / 无通量 / 固定值）及其生物学对应；
- **compartment 模型**：把空间离散成若干均匀混合的"舱"（细胞器、细胞、组织区室），舱内 ODE、舱间迁移——药代动力学与生态学的通用框架；
- **agent-based 模型（ABM）简介**：每个细胞一个智能体（规则驱动：运动、分裂、通信）；何时 ABM 优于 PDE（个体异质性、少量个体、复杂规则），代价（参数多、难以解析分析、统计推断贵）；
- 形态素梯度（morphogen gradient）的建立与解读：source–diffusion–degradation 的稳态长度标度 $\ell = \sqrt{D/\mu}$。

## 🧫 生物学场景

| 场景 | 数学看点 |
|---|---|
| **胚胎发育模式形成**：果蝇早期体轴 | 形态素梯度（bicoid）建立位置信息；French flag 模型（浓度阈值分区） |
| **图灵斑图的天然范本** | 哺乳动物毛色（发芽期条纹 → 成年斑纹，Kondo & Miura 2010）、鱼类条纹（如鳉鱼色素细胞）、小鼠指/趾数（Hox 基因波动，Sheth et al. 2012） |
| **形态素梯度解读** | 梯度加噪声的读出鲁棒性（连接 Stage 02） |
| **细菌菌落生长** | 趋化环（*E. coli* 的 Swiss-cheese 图样）、生物膜的空间结构 |
| **肿瘤浸润边界** | 移动边界问题（Fisher 波前端速度 $v = 2\sqrt{D r}$，选读） |
| **多尺度例子：从分子扩散到组织梯度** | 同一 $D$ 在 μm 尺度与 mm 尺度给出完全不同的时间（$t \sim L^2/D$：1 μm 毫秒级，1 mm 数小时）——**尺度决定时间**是本阶段的反复主题 |

## 🏁 里程碑项目：`stage03-pattern` —— 图灵斑图的数值模拟与参数转捩

**一句话**：实现两组分反应扩散系统，亲手把参数从"均匀稳定"推向"斑图"区，观察斑点 / 条纹的诞生与转捩，并用线性稳定性分析预测临界参数与特征波长。

### 项目流程

1. **选模型**：Gierer–Meinhardt、Schnakenberg 或 Gray–Scott（三者任选其一，建议 Schnakenberg：参数少、判据干净）：
   $$\frac{\partial u}{\partial t} = D_u \nabla^2 u + f(u, v), \qquad \frac{\partial v}{\partial t} = D_v \nabla^2 v + g(u, v)$$
2. **数值实现**：二维规则网格（如 128×128，周期边界）显式有限差分；先在稳定性条件内运行；实现"快照保存"（每 N 步存一张图）；
3. **验证无扩散项**：$D_u = D_v = 0$（或极小）时退化回 Stage 01 的 ODE 行为；再验证纯扩散（$f=g=0$）把任意尖峰抹平——**两个极限都对了，耦合才可信**；
4. **参数扫描**：固定反应参数，扫描 $D_v/D_u$（抑制剂扩散优势）与总反应强度：
   - 记录"均匀态 / 斑点 / 条纹 / 时空混沌"四类结局，绘制参数相图；
5. **线性稳定性对照**：在均匀定态处对每个波数 $q$ 解 2×2 线性问题（Stage 00 讲义 02 的矩阵技能直接复用！），求出失稳临界 $q_c$ 与预测波长 $\lambda_c = 2\pi/q_c$；与模拟中实测斑图间距对照；
6. **转捩实验**：沿相图的一条线缓慢连续改变参数（quench 实验），观察条纹 ↔ 斑点的转捩路径与滞后。

### 通过标准

- [ ] 数值格式在稳定性条件边界处表现符合预期（$\Delta t$ 越界即数值爆炸——亲眼见过一次）
- [ ] 线性预测波长与模拟实测波长一致（相对偏差 < 15%）
- [ ] 一份 notebook：模型推导 + 数值方法说明（含稳定性条件的推导）+ 斑图演化快照 + 参数相图 + 波长对照 + 一页讨论
- [ ] 能口头回答："为什么图灵要求激活子扩散慢、抑制剂扩散快？"
