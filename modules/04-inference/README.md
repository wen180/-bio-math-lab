# 📊 Stage 04 · 数据驱动与参数推断：从数据反推模型

> **周期**：4–6 周 ｜ **前置**：Stage 00（MLE、贝叶斯公式、`curve_fit`）；建议完成 Stage 01（里程碑数据来源）
> **一句话**：前面的阶段都在解**正问题**（模型 + 参数 → 预测）；科学日常却是**反问题**（数据 + 模型 → 参数，甚至 → 模型本身）。本阶段把"拟合"从工程技巧升级为统计推断的完整理论。

---

## 🎯 出发点

生物学参数大多**不可直接测量**：启动子活性、降解率、 Hill 系数……我们测到的只是它们的**投影**（荧光时间序列、计数分布、斑图波长）。反问题普遍**不适定（ill-posed）**：

- 不同的参数组合可能给出几乎相同的预测（**不可识别**）；
- 数据有限 + 噪声存在 ⟹ 点估计天生不完备，**必须携带不确定度**；
- 模型比较（负反馈 vs 无反馈）不能只看"谁的曲线更贴"。

本阶段的主线工具链：**噪声模型 → 似然 → 后验分布 → 模型比较**。

## 🎯 学习目标

1. 把任何拟合问题明确写成统计推断：**先写噪声模型，再写似然**（高斯 → 最小二乘；泊松 → 泊松似然）；
2. 判断参数**可识别性**（identifiability）：结构性（换组初值仍同一解？）与实际性（这套数据够吗？），用 profile likelihood 实操诊断；
3. 完整实现贝叶斯推断 pipeline：先验（生物学合理范围）→ 似然 → 后验；理解"后验 ∝ 似然 × 先验"在每次实战中意味着什么；
4. 写出 MCMC 的原理（Metropolis–Hastings 的接受规则为什么正确），并掌握收敛诊断（trace plot、R-hat、ESS）；
5. 会做**模型比较**：AIC / BIC、交叉验证、（选读）贝叶斯因子与 LOO；
6. 用后验预测检验（posterior predictive check）问"我的模型哪里不对"。

## 🧠 核心概念清单

- **反问题（inverse problem）与不适定性**：正问题 $ \theta \mapsto y(\theta)$ 好条件；反问题多对一
- **最小二乘与加权**：异方差数据（噪声随信号变大）必须加权；多数据类型（时间序列 + 终点测量）的联合目标函数
- **噪声模型决定似然**：
  - 加性高斯：$\mathcal{L} \propto \prod \exp\left[-\frac{(y_i - f(t_i;\theta))^2}{2\sigma_i^2}\right]$（= `curve_fit` 的默认）
  - 泊松计数：$\mathcal{L} \propto \prod \frac{\mu_i(\theta)^{y_i} e^{-\mu_i(\theta)}}{y_i!}$
  - 乘性 / 对数正态噪声：生物学数据的常态（Stage 00 思考题的正式答案）
- **参数可识别性**：结构可识别（数学上唯一）vs 实际可识别（这套数据 + 这个噪声下唯一）；**profile likelihood**：固定一个参数扫描其余优化，看置信区间的形状（扁平谷 = 不可识别）
- **贝叶斯推断**：先验（信息量的来源：量纲分析、文献范围、物理约束）/ 似然 / 后验 / 证据 $P(D)$；MAP vs 后验均值 vs 后验中位数
- **MCMC 采样**：Metropolis–Hastings 接受概率 $\alpha = \min\left(1, \frac{p(\theta')\,P(D\mid \theta')}{p(\theta)\,P(D\mid \theta)}\right)$；emcee（仿射不变 ensemble sampler）与 PyMC 的选型；诊断（trace、$\hat R$、ESS、后验预测）
- **模型选择**：AIC/BIC 的罚项逻辑；K 折交叉验证；WAIC/LOO（选读）；**奥卡姆剃刀的贝叶斯形式**（能解释一切的模型自动被证据惩罚）
- **后验预测检验**：从后验抽参数 → 生成模拟数据 → 与真实数据对比残差结构（系统性偏差 = 模型缺失项的证据）

## 🧫 生物学场景

| 场景 | 数学看点 |
|---|---|
| **从时间序列荧光数据估计启动子活性** | 隐藏状态推断：测的是蛋白荧光，问的是转录速率（ODE + 噪声 → 后验） |
| **模型比较：负反馈 vs 无反馈基因回路** | 同一数据、两个模型：交叉验证 / LOO 判别；奥卡姆剃刀自动上线 |
| **单细胞 mRNA 计数分布拟合**（连接 Stage 02） | 泊松 vs 负二项（两态启动子）：似然函数直接换；burst 频率与大小的可识别性 |
| **repressilator "伪实验"数据** | 本阶段里程碑的舞台：参数恢复 + 不确定度报告 |
| **ODE 参数的先验从哪来** | 量纲（降解率的合理区间）、文献半衰期表、物理上限（一个细胞不能有一摩尔蛋白）——先验是建模的一部分，不是数学装饰 |

## 🏁 里程碑项目：`stage04-inference` —— repressilator 数据的完整贝叶斯推断

**一句话**：拿 Stage 01 里程碑用过的 repressilator 模型生成带噪声的"伪实验"数据（真值已知），做一次教科书级的贝叶斯分析——**以后面对真数据，流程不变**。

### 项目流程

1. **生成数据**：用 Stage 01 的 6 变量 repressilator 模型，取代表性参数，生成 3 个蛋白在若干时间点、带测量噪声的时间序列（真值密封保存，拟合结束后才开封对照）；
2. **搭建似然**：明确噪声模型（建议加性高斯起步，选做换乘性）；实现 `log_likelihood(theta, data)`——所有贝叶斯计算的原子单位；
3. **设定先验**：为每个参数写下生物学合理区间与依据（一句话一条，写进 notebook）；
4. **采样**：用 PyMC（NUTS）或 emcee 采样后验；起步前先用 `curve_fit` 找 MAP 作为热身与初值；
5. **诊断**：trace plot、$\hat R < 1.01$、ESS 足够；**不达标的采样结果不许进报告**；
6. **报告**：
   - 后验分布矩阵图（corner plot：边缘分布 + 参数两两耦合——耦合的细长谷 = 不可识别方向）；
   - 真值 vs 后验：参数是否被后验区间覆盖？
   - 后验预测检验：抽 50 组后验参数模拟数据带，与真实数据同图；
   - 讨论：哪些参数可识别、哪些不可、为什么（联系 Hill 系数与降解率的补偿）；
7. **选做模型比较**：把数据同时喂给"有第三个抑制位点"和"只有两个位点"的退化模型，用 LOO / 交叉验证判断能否分辨。

### 通过标准

- [ ] 全部采样诊断通过（$\hat R < 1.01$，每个参数 ESS > 400）
- [ ] 真值落在各自 95% 后验可信区间内
- [ ] corner plot 中至少指出一个参数耦合方向并给出物理解释
- [ ] 一份 notebook：数据生成 → 似然 → 先验 → 采样 → 诊断 → 报告 → 讨论，全流程可复现（固定种子）
