## 🎯 出发点：为什么"模型约束 AI"不是口号

裸的神经网络作为科学模型有三个结构性缺陷：

1. **不懂守恒与不变性**：它不知道总质量该守恒、浓度非负、解关于某对称性不变——训练分布之外立即胡说（外推失效）；
2. **不吃量纲**：输入单位换一下（mM → μM），网络输出系统性漂移；
3. **参数无物理意义**：一百万个权重不对应任何可测量的生物量。

反过来，机理模型有三个对称的痛点：

1. 机理永远**不完整**（你知道 Hill 函数形式，不知道系数，甚至不知道遗漏了哪个相互作用项）；
2. 解算**贵**（大 PDE、长 MCMC）；
3. 写全模型的**人力**有限。

混合建模（mechanistic + data-driven）的分工：**机理负责结构与约束（方向盘与刹车），神经网络负责残差与未知项（引擎的额外马力）**。本阶段学的是这条哲学的工具化版本。

## 🎯 学习目标

1. 理解 **PINN 的损失函数结构**：数据项 + 方程残差项（自动微分算出 $\partial u/\partial t$、$\nabla^2 u$）+ 边界 / 初值项，以及三项之间的权重是真正的建模决策；
2. 区分**正向问题**（解方程，PINN 当求解器）与**逆向问题**（学方程中的未知参数，PINN 当推断器）——后者才是生物学更常需要的；
3. 建立**可微编程**思维：整个模拟器变成可微计算图后，梯度可以从最终损失一路反传到参数（对比 Stage 04 的外层优化器 + 内层求解器）；
4. 了解**代理模型**（surrogate model）：用网络近似昂贵模拟器的输入–输出映射，再在代理上做扫描 / 推断；
5. 能批判性评估一篇 AI×科学论文：约束在哪一层（损失 / 结构 / 数据）、外推如何被检验、与基准数值方法的对照是否公平。

## 🧠 核心概念清单

- **物理信息神经网络（PINN, physics-informed neural network）**：
  $$\mathcal{L} = \underbrace{\mathcal{L}_\text{data}}_{\text{稀疏观测}} + \lambda_1 \underbrace{\mathcal{L}_\text{PDE}}_{\text{配点上方程残差}} + \lambda_2 \underbrace{\mathcal{L}_\text{BC/IC}}_{\text{边界 / 初值}}$$
  其中 $\mathcal{L}_\text{PDE}$ 由**自动微分（autodiff）**计算网络输出对输入的导数——"约束"就是"把方程写进损失函数"
- **自动微分**：forward / reverse 模式的区别；autodiff ≠ 数值差分 ≠ 符号微分；为什么 PyTorch / JAX / Julia 生态成为科学计算新基建
- **可微编程（differentiable programming）**：可微 ODE 求解器、可微似然；端到端梯度让"模型 + 数据"联合训练成为可能（Neural ODE 的核心思想：把 ODE 求解器放进计算图）
- **代理模型（surrogate model）**：高斯过程 vs 深度网络；训练集来自机理模型采样（仿真循环 → 学习 → 加速仿真循环）；主动学习采样（在哪里补样本最值）
- **通用物理 / 机理约束的机器学习**（physics- & mechanism-constrained ML）：约束进损失（软）、进结构（硬：守恒层、对称等变网络、正输出激活）、进数据（增广）；软 vs 硬约束的取舍
- **混合建模（hybrid mechanistic + data-driven）**：已知部分写方程、未知部分留网络（universal differential equations：$\frac{du}{dt} = f_\theta(u) + g(u)$ 中 $g$ 用学到的网络补全——把"发现未知动力学"变成参数学习）
- （概念性）**数据同化**：状态估计 vs 参数估计；与贝叶斯滤波（Kalman / particle）的一句话关系

## 🏁 里程碑项目：`stage05-pinn` —— PINN 求解反应扩散方程，与有限差分对照精度

**一句话**：用 PyTorch 实现 PINN 求解一维反应扩散方程，用 Stage 03 的有限差分解当裁判，量化"神经解法 vs 数值解法"的精度 / 速度 / 灵活性权衡——**对照必须严格**，这是本仓库"数学约束 AI"原则的自我实践。

### 项目流程

1. **选方程**：一维 Fisher–KPP 方程（有解析行波可供第三重对照）：
   $$\frac{\partial u}{\partial t} = D\frac{\partial^2 u}{\partial x^2} + r\,u(1-u), \qquad u(x, 0) = u_0(x), \ u(0,t) = u_L,\ u(L,t) = u_R$$
2. **基准解**：实现（或复用 Stage 03 的）显式有限差分解，网格收敛性检查（减半 $\Delta x$ 看解是否稳定）——**裁判必须先经过认证**；
3. **PINN 实现**：
   - 网络：输入 $(t, x)$、输出 $\hat u$；MLP（如 4 层 × 64 神经元，tanh 激活）；
   - 损失三项：初值点上的 $\mathcal{L}_\text{IC}$、边界点上的 $\mathcal{L}_\text{BC}$、内部配点上的 $\mathcal{L}_\text{PDE}$——**配点采样策略**（均匀 vs 随机重采样）本身就是实验变量；
   - 用 `torch.autograd.grad` 对网络输入求 $\partial \hat u/\partial t$ 与 $\partial^2 \hat u/\partial x^2$；
4. **精度对照**：在独立测试网格上报告相对 $L^2$ 误差随训练轮数的变化曲线；PINN 与有限差分解同图叠加，误差场（$|u_\text{PINN} - u_\text{FD}|$）单独成图——**误差在哪儿大？为什么？（通常在波前陡峭处）**；
5. **逆向问题（本项目的真正高潮）**：假装 $D$ 与 $r$ 未知，只给少量稀疏观测点（如 5% 的时空采样），把 $D, r$ 设为可训练参数随网络一起训练——恢复值与真值误差 < 5% 即成功（这一步做完，"PINN = 可微模拟器 + Stage 04 的推断"的图景自然浮现）；
6. **讨论**：什么时候 PINN 值得用（高维、反问题、无网格复杂几何），什么时候有限差分完胜（低维正问题——快几个数量级）。**诚实报告劣势**是本项目的加分项。

### 通过标准

- [ ] 正问题：测试集相对 $L^2$ 误差 < 5%（对 Fisher–KPP 的光滑解）
- [ ] 逆向问题：$D, r$ 恢复误差 < 5%
- [ ] 一份 notebook：三项损失的定义、配点策略、训练曲线、误差场、FD 对照、逆向结果、诚实的讨论
- [ ] 能口头回答："为什么 PINN 在低维正问题上打不过有限差分，却仍被科学界重视？"
